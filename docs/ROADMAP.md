# Roadmap

The roadmap is directional. A listed item is not implemented or supported.

## v0.1 - context foundation

- one complete `build-work-context` skill;
- ordinary-chat DOCX and Markdown starter;
- professional context, project capsule, working pack, and change summary;
- synthetic ClinPharm/pharmacometrics proof;
- privacy, compatibility, benchmark, and contribution contracts.

## v0.2 - validated portability

- complete synthetic runtime matrix across major hosts;
- improve interview behavior from human review;
- extend deterministic Markdown-to-DOCX release tooling;
- optional project-instruction adapters;
- expand signed/versioned release and installation guidance.

## v0.3 - evidence workflow

Candidate, not yet approved:

- `pharma-evidence-brief`;
- source manifests and claim ledgers;
- update and contradiction workflows; and
- interoperability proof with selected community skills.

## v0.4 - ClinPharm and pharmacometrics

Candidate, not yet approved:

- `clinpharm-review`;
- `pharmacometrics-qc`;
- a public synthetic benchmark package;
- reproducibility and evidence-consistency checks; and
- explicit qualified-human sign-off.

## Later department skills

Add only after a real instance, public-safe workflow, and validation path exist:

- regulatory comment review;
- medical affairs evidence brief;
- clinical operations brief;
- safety signal briefing;
- CMC/quality evidence pack; and
- market-access or strategy context.

## Explicit non-roadmap

The current repository does not promise:

- autonomous agents;
- patient-level analysis;
- clinical decision support;
- GxP validation;
- external submission or publishing;
- enterprise connectors;
- a hosted SaaS; or
- replacement of professional judgment.
